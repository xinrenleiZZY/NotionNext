## 三、三条主线项目深度复盘

### 🔥 主线一：HZX 采购管理系统 — 从 0 到生产级的三服务架构

这是我修仙路上第一个真正的「元婴」。

**架构总览：**

```
                 ┌───────────────────┐
                 │   hzx-web:7500    │  Next.js 15 · 前端界面
                 └────────┬──────────┘
                          │ HTTP
                 ┌────────▼──────────┐
                 │   hzx-api:7501    │  FastAPI · 后端 API
                 └────────┬──────────┘
              ┌───────────┼───────────┐
              ▼           ▼           ▼
         [SQLite/PG] [Redis Queue] [文件存储]
                          │
                 ┌────────▼──────────┐
                 │   hzx-monitor     │  飞书 Bot · 监控告警
                 └───────────────────┘
```

**三大设计决策：**

1. **健康检查优先于依赖**：`depends_on: condition: service_healthy`，API 健康检查通过后 Web 才启动，避免「启动即报错」
2. **飞书作为消息总线**：所有告警、日报、审批卡片统一走飞书 Bot，不单独装邮件服务 / 钉钉
3. **共享卷解耦配置**：把业务配置文件挂载到宿主机目录，升级镜像时配置零丢失

**踩过的三大坑：**
| 坑 | 原因 | 解法 |
|---|------|------|
| 容器时区不一致导致定时任务偏移 | 默认 UTC | Dockerfile 里强制 `TZ=Asia/Shanghai` |
| 飞书 Token 2h 过期 | 只在启动时获取 | 封装 `get_token()` 自动刷新 + 缓存 |
| Next.js 构建内存爆掉 | 服务器 1G RAM | 开启 `SWAP` + 调整 `NEXT_TELEMETRY_DISABLED=1` |

### 🤖 主线三：Dify 多模型 AI 工作流落地

AI 是 2026 年最大的变量，也是效率提升最猛的武器。

**四模型分工策略（我实测最佳实践）：**

```
用户需求
   ↓
 Deepseek-Chat    ← 便宜、速度快 · 70% 日常编码 & 中文任务
   ↓（需要强逻辑时）
 Claude-3-Opus    ← 长上下文、严谨 · 代码审查 / 架构重构
   ↓（需要创意时）
 GPT-4-Turbo      ← 发散性好 · 文案写作 / 头脑风暴
   ↓（最终输出）
 GPT-4o-Mini      ← 性价比极高的最终润色 & 格式化
```

**三大工作流模板（我高频使用）：**
1. **智能内容生产线**：大纲→扩写→代码示例→润色→发布
2. **代码 Review 流水线**：Claude 静态分析→Deepseek 运行测试→GPT-4 总结建议
3. **知识产权辅助分析**：上传合同/报告→RAG 检索判例→生成风险清单（*这个我最常用*）

## 四、修仙感悟 · 四句心法

### 1. 关于学习：解决问题的思路 > 语言细节

技术永远学不完。但**本质思维**是相通的：
- 任何复杂系统，拆成「输入-处理-输出」就清晰了
- 任何 Bug，**二分法定位**是最快的（不要一行行 Print）
- 遇到报错不要急着 Copy 到搜索框，先读 3 遍 Stack Trace

### 2. 关于开源：你的代码是思考的痕迹

> 「开源不是炫耀，而是知识的沉淀。」

**仓库不在多，在于你敢不敢写 README**—— 这是我这一年最大的心得。
当你把一个项目 README 写清楚，你就把思路重新整理了一遍。比什么笔记都管用。

### 3. 关于工作：技术只有服务于业务，才有真正的价值

在 **广州聚星知识产权有限公司** 的这一年，让我深刻体会到：

> 再精妙的架构，再先进的模型，如果不能帮客户把「数据资产」变成「受保护的知识产权」，就是零。

所以现在我做任何技术选型，第一问不是「酷不酷」而是：
**这个技术能帮业务省多少时间 / 赚多少钱 / 规避多少风险？**

### 4. 关于身体：修仙的本钱是肉身

- 写代码每 **45 分钟**站起来走一圈
- 熬夜最多到 **1 点**，第二天必须补觉
- 颈椎病：买个人体工学椅，ROI 比任何电脑升级都高
