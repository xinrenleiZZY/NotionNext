# 七夕特辑：当代码写满浪漫——qixi-sur 项目揭秘

## 项目简介

`qixi-sur` 是一个用纯 HTML 写成的七夕浪漫页面。没有复杂的技术栈，没有华丽的框架，纯粹的前端代码就能表达最真挚的心意。

> 有时最好的代码，是写给心爱的人看的。

## 技术构成

```html
<!DOCTYPE html>
<html>
<head>
    <title>七夕快乐</title>
    <!-- 纯粹的 HTML + CSS + JS -->
</head>
<body>
    <!-- 爱心粒子动画 -->
    <!-- 情书滚动效果 -->
    <!-- 背景音乐 -->
</body>
</html>
```

## 核心特效

### 1. 粒子爱心动画

使用 Canvas 绘制粒子系统，粒子汇聚成爱心形状，并不断呼吸闪烁。

### 2. 滚动情书

当用户滚动页面时，情书内容渐入，配合柔和的动画效果。

### 3. 背景音乐

嵌入温馨的背景音乐，自动播放（需用户交互后）。

## 如何定制

Fork [qixi-sur](https://github.com/xinrenleiZZY/qixi-sur) 仓库，修改 `index.html` 中的：

- 情书内容
- 配色方案
- 背景音乐链接
- 动画参数

## 浪漫编程心得

1. **简单就是最好的** — 不需要复杂的框架，真实的情感来自简洁的表达
2. **细节决定感动** — 微小的动画、恰到好处的节奏，比花哨的效果更打动人
3. **代码也是情书** — 每一行精心编写的代码，都是心意的载体
