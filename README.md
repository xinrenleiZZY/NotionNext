## 🚀 本地开发

```bash
# 1. 安装依赖
yarn

# 2. 启动开发
yarn dev
```

| 命令 | 用途 |
|------|------|
| `yarn dev` | 启动本地开发 |
| `yarn build` | 构建生产版本 |
| `yarn export` | 静态导出 |

## 📦 部署

本站部署在 **Vercel**，使用 `NOTION_PAGE_ID` 环境变量连接 Notion 数据库。

部署步骤：
1. Fork 本仓库
2. 在 Vercel 导入项目
3. 配置环境变量 `NOTION_PAGE_ID`
4. 部署完成
